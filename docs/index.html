WaveCast

Free, ad-free podcast streaming player powered by the Apple iTunes Directory & open RSS feeds.

Download APK (v1.0.0) Install via Obtainium GitHub Repo

App Preview

🔍

Free Directory Search

Search millions of podcasts across Technology, News, True Crime, Comedy, and Science powered by iTunes Search API with no API keys or accounts required.

⚡️

Native Background Audio

Continuous playback powered by @rntp/player with full lock screen, notification shade controls, and headphone buttons support.

🎚

Smart Player Controls

Customizable skip intervals (10s, 15s, 30s), variable speed playback (1.0x to 2.0x), full scrub timeline, and episode show notes.

🛡

100% Free & Open Source

Zero advertisements, no third-party tracking, no subscriptions. Everything is transparent and open under the MIT license.
